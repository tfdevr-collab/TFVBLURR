# TFV//BLUR — root-file edition

This edition is configured for GitHub Pages with every file in the repository root. No `assets` folder is required.

## Upload structure

Keep `index.html`, `style.css`, `script.js`, `README.md`, the seven `artwork-XX.jpg` files, `skit-halo.jpg`, and `tfv-blur-mark.svg` together in the repository root.

The image paths in the HTML and JavaScript are root-relative (for example `artwork-01.jpg`).

GitHub Pages should publish from branch `main`, folder `/(root)`.
